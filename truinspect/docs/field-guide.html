00 · Before you start

What you need

TruInspect is a web app that installs to your phone like a normal app — there is nothing to download from an app store.

A phone with a camera
Android or iPhone. The guided camera and licence-disc scan need a rear camera and an HTTPS connection.
The web address
https://inspect.tru-saas.com — open it in your phone's browser. On iPhone this must be Safari (see below).
Your access code
A per-dealership code from your manager — the same code across the TruDealer apps, set for your dealership in TruFlow. It links this device to your dealership; inspectors cannot self-register.
Signal to start
You need a connection the first time to install and sign in. After that the app runs offline — photos are kept on the phone and upload when you're back online.
Good to know

You sign in once per device. The code is stored as a signed device token for ~30 days, so you land straight on your vehicle list every time you open the app.

01 · Get it on your phone

Install the app (PWA)

Installing puts a TruInspect icon on your home screen and runs it full-screen with no browser bar — the way you'll want it next to a car. The install control also lives permanently inside the app under the App panel, so you're never locked out if you dismiss a prompt.

On iPhone or iPad

  1. Open the site in Safari

    Go to inspect.tru-saas.com. Chrome and Edge on iPhone cannot install it — it has to be Safari.

  2. Tap Share

    Tap the Share icon (the square with an up-arrow) in Safari's toolbar.

  3. Add to Home Screen

    Scroll down the share sheet and tap Add to Home Screen.

  4. Tap Add

    Confirm with Add, then open TruInspect from your home screen icon.

On Android (Chrome / Edge)

  1. Open the site

    Go to inspect.tru-saas.com. You may see a one-tap Install TruInspect banner — if so, tap it and you're done.

  2. Or use the browser menu

    Open the browser menu (⋮) and tap Install app or Add to Home screen.

  3. Open from the home screen

    Launch TruInspect from its new icon — it opens full-screen.

If you don't see an install option

Installing needs an HTTPS page, and some browsers only offer the one-tap prompt after a couple of visits. The prompt also appears only once per visit — reload the page to get it back, or use the browser menu. Inside the app, the App panel always shows either Install TruInspect or How to install with these same steps.

How you know it worked

Once installed, the app's App panel reads “TruInspect is installed on this device.” and the app opens without a browser address bar.

02 · Register the device

Sign in with your code

The first screen is Inspector sign-in. It has one field — the access code for your dealership. There is no email or password.

  1. Open TruInspect

    You'll see the TruInspect wordmark, then “Inspector sign-in — This device is registered to one dealership.”

  2. Type your access code

    Enter it in the Inspector access code field. Tap the eye icon to reveal what you typed — handy outdoors on a phone. A note warns you if Caps Lock is on.

  3. Tap “Use this device”

    The button shows Checking code… while it verifies. On success you go straight to your vehicle list. The device stays signed in.

If the code is refused

“That code is not recognised” means the code is wrong or your dealership isn't set up for TruInspect yet. Access is issued per dealership — ask your manager for the code, or contact TruSaaS to set your team up. If the screen instead says “No access code is set on this server,” that's a setup step on the TruSaaS side, not something you can fix from the phone.

03 · Where everything starts

The home screen

You land on your vehicle list — “Photography, inspections & trade-in appraisals.” Search and filter by status, see readiness badges and fleet stats, and add cars. Each vehicle card carries the same four buttons.

Add a vehicle

Tap Add vehicle and fill in the details, or tap the licence-disc scanner and hold the camera over the disc — TruInspect reads the barcode and pre-fills make, model, colour, VIN and year for you.

The four buttons on every card

Two are workflows (the work you do), two are documents (what comes out). Photo capture is the first step inside each workflow, not a separate button.

▤ Inspect
Start a full inspection: capture the shot list, rate condition, check function. → produces the VIR.
◫ Trade-In
Start a trade-in appraisal: walk-around, live valuation, signed offer. A teal tick appears once appraised.
▦ VIR
Open the Vehicle Inspection Report for this car (even before it's finished).
▧ TIR
Open the Trade-In Appraisal Report for this car.
One photo, both flows

Inspect and Trade-in share the same set of vehicle angles. A shot you take in one flow shows up in the other automatically — you never re-shoot the same angle twice for the same car.

Need a hand mid-job

The floating DealerAssist chat and the in-context Guide panel are available on every screen if you get stuck.

04 · Workflow A

Run an inspection (VIR)

A guided 27-slot photo walk-around in three phases, then condition & function ratings, damage tags, a review, and a printable Vehicle Inspection Report. Tap Inspect on the vehicle card to begin.

  1. Capture the shot list

    The camera opens on the guided walk-around. Work through the three phases in order:

    Phase 1 — Front & Engine · bonnet, engine bay, front bumper & grille, front windscreen, licence disc.

    Phase 2 — Clockwise Exterior Walk-Around · around the car from the front-right, through every wheel, door, quarter and fender, boot/tailgate and rear bumper, back to the roof.

    Phase 3 — Interior, History & Verification · steering & controls, cabin, service book, odometer, spare keys.

    Each slot shows a coaching line telling you where to stand. Use Shoot for the live camera or Import to add a photo from the gallery; keep a shot or retake it. 23 of the 27 are required; optional items (spare wheel, jack, roof/sunroof, spare keys) show Not present — skip this item.

  2. Rate each shot as you go

    After a capture you can record the panel's condition and add a note or close-up right there, so grading happens at the car, not from memory.

  3. Tag any damage

    Open Tag damage and tap the spot on the real photo. Set the panel, damage type and severity 1–5, and add close-ups. Tagging is fully manual — the report grade is built only from what you record, never a black-box guess.

  4. Work the inspection checklist

    Open the Checklist (screen title “Inspection”). Points are grouped into Exterior · Glass & lights · Wheels & tyres · Interior · Engine & underbody · Identity & documents. Each point uses the buttons that fit it:

    OKNoteDamage·Present / Not PresentFSH / Partial / NoneWorks / Faulty / N/A

    Use All OK to pass everything still unanswered in one tap, then override the exceptions. The header tracks “done” and how many items are flagged “to disclose.” Tap Save as you go.

  5. Review & submit

    The “Review & submit” screen shows “N of 27 shots,” a tick per phase when it's complete, and a 6-across grid of every shot (tap one to retake). It flags any missing required shots and any damage. When all required shots are in, tap Submit inspection.

  6. Produce the VIR

    The Vehicle Inspection Report opens with an overall condition band on a 1.0–5.0 scale (5.0–4.5 Excellent / retail-ready, down to 2.4–1.0 Poor), panel grades, the damage list and your dealership branding. Add the inspector and customer details, then Print or tap PDF to download. Reports are numbered like VIR-2026-00847. Reopen it any time from the card's VIR button.

The condition score is honest

The 1.0–5.0 band is computed only from real inspector inputs — the panels you graded and the damage you tagged. No photo is “scored” by a machine.

05 · Workflow B

Run a trade-in appraisal

A step-by-step walk-around that captures condition and reconditioning cost at every stop, then values the car against the live market and prints a signed offer. Tap Trade-In on the vehicle card to begin — the screen is titled “Trade-in appraisal.”

Step 1 · The walk-around

You move through the car one stop at a time — 27 stops across Front & Engine, Clockwise Exterior, and Interior, History & Verification. The header keeps a running R … recon total and a progress bar; the dots at the bottom jump you to any stop. At each stop (titled “Step N: …”) you set:

Photo
Optional for most stops (“Photo optional — tap to add”). It becomes required — shown with a red border — whenever you enter a repair cost, and always for the odometer. Use Retake to redo it.
Status
The toggle fits the item:
OKDamaged
ValidExpiredMissinglicence disc
FSHPartialNo Bookservice book
PresentNot Presentspare wheel, jack, keys
Condition
GoodFairPoorNeeds Recon
Repair / replacement cost (R)
The estimated recon spend for that item. Marking a stop Damaged (or its equivalent) turns the cost field red and asks for a photo. Everything you enter rolls into the header's recon total.

Good items left on their defaults are marked complete automatically, so you can move quickly and only stop for what needs attention. Use Prev / Next, and on the last stop tap Continue to Valuation.

Step 2 · Market valuation

The “Market Valuation” screen assesses the live market for you — “Assessing live market…” — scanning dealer stock and SA classifieds for your exact year/make/model. You can also:

  • Open AutoTrader or Cars.co.za directly to check listings by hand.
  • Pull a TU Valuation (TransUnion trade/retail/new prices) and run a Reg Check for stolen / outstanding-finance flags.

Set the Average market retail price (R), confirm the read-only Total recon costs, and set your Dealer margin % (this is hidden from anything the customer sees). The offer is calculated live:

Final trade-in offer = ( retail − recon ) × ( 100 − margin ) %

A price-history trend appears if you've valued this car before. When a price is set, tap Continue to Summary.

Step 3 · Summary & signed offer

The “Trade-in summary” shows the market average against your offer, the condition summary and the Valuation build-up (every adjustment, including the margin & reconditioning line). The offer is stamped valid 7 days from inspection. Add the inspector's name and phone, then capture sign-off in the Dealer Sign-Off panel — the customer signs on the Digital signature canvas right on the phone (Clear to redo).

Export with HTML, Print or PDF, and finish with Save Trade-In Appraisal. The saved report (numbered like TIV-2026-00847) reopens any time from the card's TIR button, and the card shows a teal tick.

Margin stays private

The dealer margin drives the offer but never appears on the customer-facing export — the customer sees the market average, the recon deductions and the final offer, not your margin %.

06 · Help that travels with you

DealerAssist & Guide

Two kinds of help ride along on every screen — reach for them before you get stuck, without leaving the job.

✦ DealerAssist
A floating AI chat, open on any screen from the assistant button. Ask it how a step works, what a status means, or how the offer is calculated — it answers in plain language, in place.
◈ Guide panel
In-context help that changes with the screen you're on. Open it during capture, the checklist or the valuation for a quick reminder of what that screen expects.

07 · When something's off

Troubleshooting

SituationWhat to do
The camera won't openAnother app may be using it — close that app and tap Retry live camera. If your browser can't open the camera at all, use Import to add photos from the gallery instead.
iPhone won't offer installYou must use Safari, not Chrome/Edge. Then Share → Add to Home Screen → Add.
The install prompt vanishedBrowsers show it once per visit. Reload the page, or use the App panel inside TruInspect, which always has the steps.
You're out of signalKeep working. Photos are saved on the phone and upload automatically once you're back online. The report just needs the shots — it grades offline.
Code isn't acceptedCheck Caps Lock and tap the eye to reveal it. If it still fails, the code is wrong or your dealership isn't enrolled — ask your manager or TruSaaS.
Wrong car detailsRe-scan the licence disc, or edit make / model / colour / VIN / year by hand on the vehicle.
Report looks emptyOpen it from VIR / TIR even mid-job — it opens to its not-started state and fills in as you capture and rate.
Rule of thumb

Get the required shots and honest condition in first — everything downstream (the VIR grade, the trade-in offer, the signed reports) is built from those. You can always reopen a car and add detail later.
